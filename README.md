# Kishore Portfolio — React

This is the uploaded portfolio converted to React without changing the portfolio's text, colors, layout structure, typography, sections, navigation labels, or links.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Files

- `src/App.jsx` — React portfolio
- `src/App.css` — original portfolio CSS
- `src/main.jsx` — React entry point
